# Interactive Business Dashboard in Streamlit

## Objective

Develop an interactive dashboard for analyzing sales, profit, and segment-wise performance using the Superstore Dataset.

---

## Features

### Interactive Filters
- Region
- Category
- Sub-Category

### Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Orders

### Visualizations
- Sales by Category
- Profit Distribution by Category
- Top 5 Customers by Sales
- Region-wise Sales Trend

### Data Table
- View filtered records dynamically

---

## Technologies Used

- Python
- Pandas
- Streamlit
- Plotly
