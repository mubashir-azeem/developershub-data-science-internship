# DevelopersHub Data Science & Analytics Internship

This repository contains internship tasks completed as part of the Data Science & Analytics Internship at DevelopersHub Corporation.

---

# Internship Objective

The purpose of these tasks is to develop practical skills in:
- Data analysis
- Data visualization
- Data preprocessing
- Machine learning
- Model evaluation using Python

---

# Completed Tasks

## Task 1 - Iris Dataset EDA
Performed exploratory data analysis on the Iris dataset using pandas, matplotlib, and seaborn.

### Skills Used
- Data loading and inspection
- Data visualization
- Exploratory Data Analysis (EDA)

---

## Task 2 - Credit Risk Prediction
Built a machine learning classification model to predict loan approval status.

### Skills Used
- Missing value handling
- Data preprocessing
- Logistic Regression
- Confusion Matrix
- Accuracy evaluation

---

## Task 3 - Insurance Claim Prediction
Built a regression model to predict medical insurance charges.

### Skills Used
- Regression modeling
- Label Encoding
- Data visualization
- MAE and RMSE evaluation

---
